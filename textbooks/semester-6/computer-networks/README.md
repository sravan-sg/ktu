# CS306 — Computer Networks Reference Textbooks

This directory contains reference textbooks and prescribed resources for **CS306 Computer Networks**.

## Prescribed Textbooks

1. **Andrew S. Tanenbaum** — *Computer Networks*, 4th Edition, Prentice Hall.
2. **Behrouz A. Forouzan** — *Data Communications and Networking*, 4th Edition, Tata McGraw-Hill.
3. **Larry L. Peterson & Bruce S. Davie** — *Computer Networks: A Systems Approach*, 5th Edition, Morgan Kaufmann, 2011.

## Reference Books

1. Fred Halsall — *Computer Networking and the Internet*, 5th Edition.
2. James F. Kurose, Keith W. Ross — *Computer Networking: A Top-Down Approach*, 6th Edition.
3. W. Richard Stevens — *TCP/IP Illustrated Volume 1*, Addison-Wesley, 2005.
4. William Stallings — *Computer Networking with Internet Protocols*, Prentice-Hall, 2004.
