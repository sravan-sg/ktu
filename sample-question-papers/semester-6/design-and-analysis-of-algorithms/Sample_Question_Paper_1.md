PART A
Answer all questions. Each question carries 3 marks.
1. Define asymptotic notations: O, Omega, and Theta.
2. State the Master Theorem for solving recurrence relations.
3. What is the greedy choice property?
4. Differentiate between P, NP, NP-Hard, and NP-Complete classes.

PART B
Answer any two full questions. Each question carries 9 marks.
5. a) Explain the time complexity analysis of Quick Sort in the worst and average cases. (6)
   b) Write the recurrence relation for Merge Sort. (3)
6. a) Solve the recurrence relation T(n) = 2T(n/2) + n log n using recursion tree method. (6)
   b) Briefly explain amortized analysis. (3)
7. a) Write an algorithm for Binary Search and analyze its time complexity. (6)
   b) Compare linear search and binary search. (3)

PART C
Answer all questions. Each question carries 3 marks.
8. What is the fractional knapsack problem?
9. Explain the principle of optimality in Dynamic Programming.
10. Describe the concept of a Minimum Spanning Tree (MST).
11. What is the graph coloring problem?

PART D
Answer any two full questions. Each question carries 9 marks.
12. a) Solve the 0/1 Knapsack problem using Dynamic Programming. Show the DP table for a small example. (6)
    b) Can 0/1 knapsack be solved using a greedy approach? Justify. (3)
13. a) Explain Kruskal's algorithm to find the MST with an example. (6)
    b) What is a disjoint-set data structure? (3)
14. a) Describe Dijkstra's algorithm for finding the single-source shortest path. (6)
    b) Does Dijkstra work for graphs with negative weight edges? Why? (3)

PART E
Answer any four questions. Each question carries 10 marks.
15. Explain Prim's Algorithm for Minimum Spanning Tree and analyze its time complexity.
16. Discuss the N-Queens problem and how it is solved using Backtracking. Show the state space tree for 4-Queens.
17. Explain the Branch and Bound technique. How is it applied to the Travelling Salesperson Problem (TSP)?
18. Prove that the Clique problem is NP-Complete by reducing it from 3-SAT (or another known NP-Complete problem).
19. Discuss the Floyd-Warshall algorithm for All-Pairs Shortest Path and trace it on a 4-vertex graph.
20. Explain the Bellman-Ford algorithm and its capability to detect negative weight cycles.
