Sixth Semester B.Tech Degree Examination (Sample Paper 2)
Course Code: CS302
Course Name: DESIGN AND ANALYSIS OF ALGORITHMS
Max. Marks: 100                                     Duration: 3 Hours

PART A
Answer all questions. Each question carries 3 marks.
1. Explain the difference between time complexity and space complexity.
2. What are the advantages of the divide and conquer approach?
3. Define the Optimal Substructure property.
4. What is a Hamiltonian Cycle?

PART B
Answer any two full questions. Each question carries 9 marks.
5. a) Solve T(n) = 3T(n/4) + n log n using the Master Theorem. (6)
   b) Briefly explain the substitution method for solving recurrences. (3)
6. a) Explain the Strassen's Matrix Multiplication algorithm and its complexity. (6)
   b) Why is Strassen's better than standard matrix multiplication? (3)
7. a) Discuss the worst-case analysis of Selection Sort. (6)
   b) Is Selection Sort a stable sorting algorithm? Justify. (3)

PART C
Answer all questions. Each question carries 3 marks.
8. Compare Greedy approach and Dynamic Programming.
9. What is a state space tree?
10. Describe the subset sum problem.
11. What does it mean for a problem to be NP-Hard?

PART D
Answer any two full questions. Each question carries 9 marks.
12. a) Explain the Matrix Chain Multiplication problem and write its DP recurrence. (6)
    b) Trace matrix chain multiplication for a sequence of 4 matrices. (3)
13. a) Explain Huffman Coding with an example character frequency set. (6)
    b) Prove that Huffman Coding produces an optimal prefix code. (3)
14. a) Describe the Job Sequencing with Deadlines problem using a greedy approach. (6)
    b) Solve a small instance of the job sequencing problem. (3)

PART E
Answer any four questions. Each question carries 10 marks.
15. Discuss the Longest Common Subsequence (LCS) problem. Find the LCS of "STONE" and "LONGEST".
16. Explain the Graph Coloring problem using Backtracking. Provide an algorithm.
17. Describe the Travelling Salesperson Problem (TSP) and how Branch and Bound provides a solution using cost matrices.
18. Explain the concept of polynomial-time reduction with a suitable example (e.g., Vertex Cover to Clique).
19. Write and explain an algorithm to find the strongly connected components of a directed graph.
20. Discuss the concept of Approximation Algorithms and explain a 2-approximation algorithm for the Vertex Cover problem.
