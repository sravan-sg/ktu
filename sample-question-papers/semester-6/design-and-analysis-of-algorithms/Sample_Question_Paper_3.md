PART A
Answer all questions. Each question carries 3 marks.
1. What is the difference between Big-O and Little-O notation?
2. Explain the basic principle of Dynamic Programming.
3. What is the difference between Backtracking and Branch & Bound?
4. Define a Hamiltonian Path in a graph.

PART B
Answer any two full questions. Each question carries 9 marks.
5. a) Explain Heap Sort algorithm and analyze its time complexity. (6)
   b) How is a max-heap constructed? (3)
6. a) Solve the recurrence relation T(n) = T(n-1) + n using substitution. (6)
   b) What are the limitations of the Master Theorem? (3)
7. a) Describe the worst-case time complexity of Insertion Sort. (6)
   b) In what scenarios is Insertion Sort preferred? (3)

PART C
Answer all questions. Each question carries 3 marks.
8. Explain overlapping subproblems in DP.
9. What is a live node in a state space tree?
10. Describe the 15-puzzle problem.
11. What is Vertex Cover?

PART D
Answer any two full questions. Each question carries 9 marks.
12. a) Explain the DP solution for finding the Longest Palindromic Subsequence. (6)
    b) What is the time and space complexity of this approach? (3)

    b) Trace the optimal merge pattern for files of sizes: 2, 3, 5, 7, 9, 13. (3)
14. a) Explain Dijkstra's algorithm for shortest paths with a trace. (6)
    b) State the time complexity of Dijkstra's algorithm using a min-priority queue. (3)

PART E
Answer any four questions. Each question carries 10 marks.
15. Explain how the Sum of Subsets problem is solved using Backtracking. Illustrate with an example.

17. Prove that the Hamiltonian Cycle problem is NP-Complete.
18. Explain the Rabin-Karp string matching algorithm and its time complexity.
19. Discuss the Ford-Fulkerson algorithm for finding the maximum flow in a network.
