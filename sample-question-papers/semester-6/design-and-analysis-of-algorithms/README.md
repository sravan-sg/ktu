## 📝 Practice Papers Overview

This directory contains three full-length, 100-mark sample examination papers formatted strictly according to the official KTU 5-part exam scheme (Parts A through E). Over 60% of the questions are analytical and numerical walkthroughs designed for rigorous self-study and exam preparation.

### 📄 Practice Papers Index

1. 📝 **[Sample Practice Paper 1](Sample_Practice_Paper_1.md)**
   - **Pattern Focus**: Standard high-yield KTU pattern matching April 2018 & December 2019 papers.
   - **Key Drills**: Asymptotic proofs ($3^{n+1}$ vs $3^{2n}$), AVL insertion (`50, 20, 60...`), Red-Black tree insertion trace, 4-matrix MCM DP parenthesization, Bellman-Ford negative cycle trace, Fractional Knapsack greedy steps, N-Queens $4 \times 4$ backtracking state space tree, LCBB TSP 4-city cost matrix reduction.

2. 📝 **[Sample Practice Paper 2](Sample_Practice_Paper_2.md)**
   - **Pattern Focus**: Alternative problem sets & advanced analytical variations matching July 2021 & September 2020 papers.
   - **Key Drills**: $\Theta(n^2)$ formal $\epsilon$-$n_0$ limit proofs, logarithmic nested loop step counts, AVL rotation sequence (`30, 40, 50, 10...`), 0/1 Knapsack DP table ($W_{max}=5$), Dijkstra 6-node min-heap trace, Strassen $P_1 \dots P_7$ equations, Kruskal Union-Find trace, 8-Queens diagonal validation formula, Non-Deterministic `Clique` search.

3. 📝 **[Sample Practice Paper 3](Sample_Practice_Paper_3.md)**
   - **Pattern Focus**: Theoretical proofs, algorithm control abstractions, and comprehensive numerical walkthroughs.
   - **Key Drills**: Mathematical asymptotic definitions ($O, \Omega, \Theta$), 3-nested loop operation count $T(n)$, AVL rotation sequence (`14, 15, 4...`), Transpose graph $G^T$, Bellman-Ford 4-pass distance updates, 5-matrix MCM DP table, Cut Property formal proof, `NDSort` pseudocode, P vs NP inclusion diagrams, $3\text{-SAT} \le_P \text{VERTEX-COVER}$ reduction concept.
