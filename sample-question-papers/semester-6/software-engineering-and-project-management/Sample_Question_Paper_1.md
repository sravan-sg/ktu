# Sample Question Paper 1 (KTU Pattern)
## CS308 — Software Engineering and Project Management

### PART A (Answer all questions, 4 x 3 = 12 marks)
1. Explain software engineering as a layered technology. (3)
2. Write the characteristics of the waterfall model for software development. (3)
3. Write the significance of Requirement analysis in software engineering. (3)
4. Discuss the maintenance aspects of software engineering. (3)

### PART B (Answer any two full questions, 2 x 9 = 18 marks)
5. (a) Explain the spiral model for software development with a neat diagram. (5)
   (b) Describe any three methods of the requirement elicitation process. (4)

   (b) Differentiate between the waterfall model and the incremental model for software development. (4)
7. (a) Write the elements of the requirements engineering process. (5)
   (b) Discuss the prototyping model. What is the effect of designing a prototype on the overall cost of the project? (4)

### PART C (Answer all questions, 4 x 3 = 12 marks)

9. Explain all the levels of the COCOMO model. (3)
10. Differentiate between code walk-throughs and code inspection. (3)
11. Draw the Rayleigh manpower loading curve and state the PNR model for staffing. (3)

### PART D (Answer any two full questions, 2 x 9 = 18 marks)

    (b) Differentiate between top-down and bottom-up design strategies. (5)

    (b) How does Black box testing differ from White box testing? (4)

Considering (a, b) = (2.4, 1.05) as multiplicative and exponential factors for the basic COCOMO effort estimation equation, and (c, d) = (2.5, 0.38) for the development time estimation equation, approximately how long does the software project take to complete? (9)
