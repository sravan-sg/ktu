## Module Overview
Module 2 covers the complete programming interface of the 8086:
- 7 fundamental addressing modes (Immediate, Register, Direct, Register Indirect, Based, Indexed, Based-Indexed).
- Instruction set functional groups: Data Transfer, Arithmetic, Logical/Shift/Rotate, String, Branching/Looping, Processor Control.
- Assembler directives (`DB`, `DW`, `SEGMENT`, `ASSUME`, `EQU`, `ORG`, `PROC`).
- Modularity techniques: Procedures vs. Macros, stack frame construction with `BP`, and parameter passing mechanisms.
