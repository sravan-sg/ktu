## Module Overview

Module 1 covers the **hardware foundation** of the 8086 — the first fully 16-bit microprocessor by Intel (1978). Understanding the 8086 is essential because it established the x86 architecture that powers every modern Intel/AMD CPU.

### Key Exam Topics (Part A: 3-mark, Part B: 9-mark)
- 8086 internal block diagram (BIU + EU) — almost guaranteed in Part B every year
- 20-bit physical address generation formula
- Minimum vs Maximum mode — comparison question appears in every paper
- Timing diagram: read cycle with T-states, ALE pulse, data valid window
- Signals: ALE, BHE#, M/IO#, RD#, WR#, HOLD/HLDA, INTR, RESET
