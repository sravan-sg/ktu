## 📖 Module Overview

Module 3 focuses on the Network Layer (Layer 3), covering Network Layer design issues, store-and-forward packet switching, Datagram vs Virtual Circuit subnets, Shortest Path Routing (Dijkstra's Algorithm), Flooding (Controlled vs Uncontrolled), Routing Protocols (Distance Vector / RIP and Link State / OSPF), and Routing for Mobile Hosts (Mobile IP, Home Agent, Foreign Agent, Care-of Address, Tunneling).
