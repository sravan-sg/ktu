## 📖 Module Overview

Module 1 introduces the foundational building blocks of computer networking, including network classification by scale (LAN, MAN, WAN), network topologies (Bus, Star, Ring, Mesh), protocol hierarchies, layer design issues, service primitives, and an in-depth comparison of the 7-layer OSI Reference Model and 4-layer TCP/IP Reference Model.
