> **Course**: CS306 Computer Networks | **Semester**: Semester 6 (S6)

## 📖 Module Overview

Module 1 introduces the foundational building blocks of computer networking, including the definition and motivations/uses of computer networks, classification by scale (LAN, MAN, WAN), network topologies (Bus, Star, Ring, Mesh), protocol hierarchies, layer design issues (Addressing, Error Control, Flow Control, Multiplexing, Routing), service primitives, and an in-depth comparison of the 7-layer OSI Reference Model and 4-layer TCP/IP Reference Model.
