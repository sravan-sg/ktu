# Module 2: Data Link Layer & Medium Access Control — Detailed Notes Index

> **Course**: CS306 Computer Networks | **Semester**: Semester 6 (S6)

---

## 📖 Module Overview

Module 2 covers the fundamental operations of the Data Link Layer (DLL) and Medium Access Control (MAC) sublayer. Topics include DLL design issues, framing methods (Bit/Byte Stuffing), CRC error detection, HDLC protocol, ARQ flow control protocols (Stop-and-Wait, Go-Back-N, Selective Repeat), IEEE 802 LAN/MAN standards (802.3 Ethernet, 802.4 Token Bus, 802.5 Token Ring), High-Speed LANs (Gigabit Ethernet Carrier Extension & Frame Bursting), Wireless LANs (802.11a/b/g/n), Bluetooth (802.15), Point-to-Point Protocol (PPP, LCP, NCP), and Layer 2 interconnection devices (Bridges & Switches with Backward Learning and Spanning Tree Protocol).
