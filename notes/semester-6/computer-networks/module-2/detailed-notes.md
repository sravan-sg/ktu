## 📖 Module Overview

Module 2 covers Data Link Layer design functions (Framing, Bit/Byte stuffing, CRC error detection, HDLC), Flow & Error Control ARQ protocols (Stop-and-Wait, Go-Back-N, Selective Repeat), Medium Access Control (ALOHA, CSMA/CD, CSMA/CA), IEEE 802 LAN/WLAN standards (802.3, 802.11), and Layer 2 network interconnection devices (Bridges, Switches).
