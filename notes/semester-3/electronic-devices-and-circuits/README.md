# CS207 — Electronic Devices and Circuits
### Semester 3 | KTU B.Tech | 3 Credits (L-T-P: 3-0-0)

> **Professor's Note:** This course forms the analogue electronics foundation that underpins every system you'll build in later semesters — from embedded systems (op-amp signal conditioning) to communication systems (oscillators, filters). Master the circuit analysis techniques here, especially the op-amp golden rules and transistor biasing, and you'll breeze through Signals & Systems, Communication Engineering, and VLSI Design.

## Exam Focus — Top Priority Topics

1. **Op-amp applications (Module 5)** — 8 circuits, all with derivations: inverting, non-inverting, summing, subtractor, integrator, differentiator, Schmitt trigger, Wien oscillator
2. **IC 555 astable + monostable design (Module 6)** — numerical problems guaranteed
3. **Transistor biasing (Module 3)** — voltage divider bias Q-point calculation = guaranteed 9-mark Part D question
4. **RC differentiator/integrator (Module 1)** — waveform conversions and τ condition analysis
5. **Oscillators (Module 4)** — Barkhausen criterion, Wien bridge frequency calculation
6. **ADC comparison (Module 6)** — Flash vs SAR vs Dual slope: speed, accuracy, applications
7. **Regulated power supplies (Module 2)** — IC 723 design, zener regulator design, SMPS block diagram

**Key Formula Sheet:** Every module's `revision-notes.md` contains a compact formula reference table.
