## Module Summary

Module 4 covers **signal generation circuits**:

- **Barkhausen criterion**: |Aβ| = 1, ∠Aβ = 0° — both conditions must be met for oscillation
- **Wien bridge oscillator**: RC frequency selective network, f₀ = 1/(2πRC), gain = 3 required
- **Hartley oscillator**: Tapped LC inductor, f₀ = 1/(2π√(L_total×C)), RF frequencies
- **Crystal oscillator**: Highest stability (Q = 10,000-10,000,000), ±1ppm drift
- **Astable MV**: Free-running, f = 0.72/RC
- **Monostable MV**: Triggered once-shot pulse, T = 0.69RC
- **Bistable MV**: SR flip-flop, two stable states, memory element
